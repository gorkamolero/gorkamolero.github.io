## Overview

This is an editorial portfolio: warm paper, dark ink, small-cap headings and
vermilion marks. Its pages should feel like an author's collected work. The
system preserves the approved pages; it is not a redesign.

The only editable source of design values is `tokens/*.tokens.json` (DTCG
2025.10). Terrazzo generates `src/styles/generated/tokens.css` and the Tailwind
v4 `@theme` in `theme.css`. The front matter above is a generated projection of
those tokens, not a second source: run `pnpm design:sync` after editing tokens.
`pnpm design:lint` checks that projection and runs Google's DESIGN.md CLI.

## Colors

Paper is the canvas; ink is the default text; ink-soft is secondary copy. Rule
is a decorative divider, not a text color. Vermilion marks links and dots. The
three gradient stops belong to primary text links and the Portfolios trigger.
Translucent surface colors preserve the original media frames and code spans.

OKLCH source colors compile to the original rounded sRGB channels, preserving
both pixel parity and sRGB gradient interpolation. Do not silently alter a
color to satisfy contrast tooling. Record any contrast finding; a palette
change requires an explicitly approved redesign. The middle and amber end of the existing
primary-link gradient have lower text contrast than WCAG AA requires (4.08:1
and 3.02:1 against paper); the lint
projection includes that pairing so the limitation remains visible.

## Typography

IM Fell English SC is the display face. IM Fell English supplies true italics;
EB Garamond is body text with oldstyle proportional numerals. Keep the Google
Fonts link in `Base.astro`, fallback families, existing sizes, line heights and
letter spacing. Token names encode the original values, not a newly invented
scale. The Tokens story displays every family and metric directly from JSON.

## Layout

`Base.astro` owns the document, metadata, Google Fonts, analytics and footer.
`PageFrame` owns the centered sheet and page context. Compose page bodies from
Astro components and slots. Keep `body[data-page]` contexts and the existing
640px breakpoint: the music and case-page typography intentionally differs.
The built URLs remain `index.html`, `koda.html`, and so on.

Use one definition per style in the owning component. `global.css` declares the
cascade layers, imports generated tokens and Tailwind utilities, and contains
the masthead/menu's shared `@scope` rules. Preflight is omitted because browser
defaults are part of the approved rendering. Page components must not import
old page stylesheets or store their body in HTML strings.

## Elevation & Depth

Use paper, rules and spacing to separate sections. Do not add shadows, raised
cards or artificial depth. Media frames retain their original surface colors.

## Shapes

Dots sit at the capitals' mid-height, 0.33em above the baseline. A separator is
0.3em wide and raised 0.18em; a leading dot is 0.42em wide and raised 0.12em.
Name dots are positioned against the masthead capitals. Use the dot tokens,
not a font bullet as a substitute for the round visual marks.

## Components

`TextLink` renders text links, never boxed buttons. Internal links show →;
external text links open a new tab with `target="_blank" rel="noopener"` and
show ↗. The existing `GitHubLink` is the approved legacy exception: its supplied
arrow stays → to preserve the owner's copy and baseline. Ordinary prose links
retain their approved styling; do not append characters to existing copy.

`Masthead` composes `PortfoliosMenu`. Desktop hover opens the pages with a 450ms
leave grace period; tolerance areas keep a 1px slip from closing the menu. A
click pins it until the next trigger click, outside click or Escape. On phones,
a tap opens the pages on lines underneath, with dots between links and never
at the start of a line. The sweep lasts 0.55s with cubic-bezier(.2,.85,.25,1).
Respect reduced motion. Retain the existing menu and carousel behaviour; add no
new client-side JavaScript to the portfolio.

Content building blocks include `WorkSection`, `CaseLead`, `MetaLine`,
`ActionRow`, `GroupHeading`, `IntroNotes`, `Figure`, `FactsList`, `PointsList`,
`ProjectIndex`, `ArchiveTable`, `Carousel`, `AudioEmbed`, `Narration`, `Job` and
`Release`. `Footer` is shared by all pages. Every component has a Storybook
story; Storybook-only examples and interaction tests do not ship in `dist/`.

## Do's and Don'ts

- Link the first mention of a company, channel, article or live product on a
  page when authoring new approved copy. Do not retroactively rewrite existing
  words, links, punctuation or entities as part of a styling task.
- Keep all design values in tokens. Change the token, regenerate, and inspect
  the dependent components; do not edit generated CSS or the front matter.
- Run build, token check, proof, parity and component screenshots after changes.
  Text and links must match exactly; the page pixel gate is 0.1%. Also report
  `pnpm parity --exact` separately. Never replace parity baselines to hide a
  regression. Inspect every diff image.
- Retain the tiny ElevenLabs widget on index and creative, the analytics
  snippet, existing public assets, fonts and footer.
- Work locally. Do not push, deploy, publish or touch the live checkout as part
  of this design-system work.
