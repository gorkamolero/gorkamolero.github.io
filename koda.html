Koda

A desktop app for working collaboratively with coding agents, where a team and its agents work on the same code together.

Working desktop build · Codex and Claude · Live collaboration on Liveblocks

Problem

Coding agents are built for one person at a time: each session lives in one developer's terminal, and the rest of the team only sees the result. Koda is built for a team and its agents working on the same code together, with sessions, workspaces and checkpoints everyone can follow.

What I Built

Koda is a desktop app for working collaboratively with coding agents. It's a Tauri shell with a React UI and a Node sidecar that runs Codex and Claude sessions in isolated git worktrees, with diffs, checkpoints, terminals and SQLite state.

Collaboration runs on Liveblocks. The host shares a workspace with a view or a control invitation, and the other person joins from their own Koda. Both see the same transcript and tool calls live. With control, the collaborator's messages go to the host's agent session, signed with their name. With view, they can only watch, and the host enforces it.

Koda paused when Claude removed the third-party access path it relied on. I brought it back on the installed Codex and Claude CLIs, and every flow now passes against the real services.

  • Shared sessionsA teammate joins the agent session live, with view or control.
  • Two agentsCodex and Claude, each with its own models, permissions and saved sessions.
  • ApprovalsApprove once or deny in the host chat. Bypass is a visible per-chat choice.

Technical Decisions

  • Run the agents through their installed CLIs, Codex's app-server and the official Claude Agent SDK, so sign-in stays with each provider.
  • Keep the Liveblocks secret on the sidecar and enforce view and control permissions on the host, not only in the UI.
  • Use a desktop shell for local filesystem, PTY, and workspace affordances that browser-only tools struggle to handle cleanly.
  • Separate the UI, desktop boundary, sidecar execution, and durable state so each responsibility stays legible.
  • Prove every flow against the real services with Playwright, from a clean clone, never with a mocked agent.

What This Proves

Koda is evidence for agent-product judgment: understanding where coding agents are heading, what makes them hard to trust, and how to design the layer where people and agents work together.
