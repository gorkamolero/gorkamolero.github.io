Agents

openroadie

Roadie · 2026 · TypeScript, React, Vite, Tailwind, React Flow, TanStack Query, Node, Express, Postgres, Redis, Vercel AI SDK, MCP, Storybook, Vitest, Playwright, Docker

The open-source context layer that came out of Roadie. It builds a graph of an organisation from the tools it already uses, around forty of them from GitHub and Jira to PagerDuty and Slack, and serves it to AI agents over MCP. Agents can only act through deterministic actions an admin has defined, with every call scoped to the caller.

I wrote much of its foundation and designed and built its interfaces, from the data-source pipelines and the relationship maps in React Flow to agent-led onboarding. Its design system, @roadiehq/ui, which I co-led, has about sixty components in Storybook, including the AI elements for agent conversations.

Koda

Desktop app · 2026 · Tauri, React, Vite, TanStack Router, Tailwind, Radix, Node, Claude Agent SDK, MCP, Liveblocks, Yjs, SQLite, Drizzle, Cloudflare Workers, xterm.js, Monaco, Storybook, Vitest, Playwright

A desktop app for working collaboratively with coding agents. A Codex or Claude session runs on your machine, and a teammate opens your workspace from their own Koda. They see the same transcript and tool calls live, and with control they can message the agent too. Their message lands in your session, signed with their name.

Every flow is proven against the real services, from Codex and Claude sessions and approvals to restarts and two-instance collaboration, with Playwright runs from a clean clone.

Recorded live: Claude on one Mac, a collaborator on another.

Claude-on-Discord

2026 · Claude Code, Claude Agent SDK, discord.js, Bun, SQLite, git worktrees, Astro

Claude Code run from Discord. Each channel is a working lane with its own repo, model, session and system prompt, and each thread can branch into its own git worktree. The agent's replies, thinking, tool calls and cost stream live into the conversation, with buttons to interrupt or stop it, and a supervisor keeps the bridge alive and recovers it after a crash.

A task in the channel streams its tool calls live, a thread takes a second change in its own git worktree, and the work merges back.

Saga and Cybertantra

2023–2026 · Python, Remotion, ffmpeg, Eleven v4, Eleven Music, OpenAI image generation, Codex, YouTube Data API, ElevenLabs Agents, Raspberry Pi

Saga is a fully automated video studio that takes a topic and publishes a finished video. In 2023 it published 205 Shorts in 34 days and grew a channel to 1,000 subscribers with zero ads. After a lot of refinement, I now use it for long-form video in a new channel, Cybertantra, with episodes up to fifty minutes long, voiced in Eleven v4, scored with Eleven Music and cut in Remotion. The talking statues are wood carvings in the Missouri woods that you can talk to, each with a Raspberry Pi inside and an ElevenLabs agent behind it.

Hotpress

Live · 2026 · Next.js, Lexical, Liveblocks, Yjs, Postgres, Drizzle, react-pdf, pdf-lib, Vercel Blob, Playwright

A collaborative writing app, like Google Docs, that also publishes complex books. Real-time editing on Lexical, Liveblocks and Yjs, a print preview, and export on demand to press-ready PDF and EPUB. Datomania

Live · 2026 · Next.js, React, Tailwind, TanStack Table, Nivo, d3, Vitest, MSW, Vercel

Spanish public data you can browse, chart and query through a public API, refreshed monthly. It holds 1,257 records of Spain's representatives from the Congreso and Senado open data, covering legislature I (1979 to 1982) and the current one. The API is paginated and serves representatives, parties and stats, with CSV and JSON export. It has 119 Vitest tests and deploys to Vercel from GitHub Actions on every push.

Headroom

Community beta · 2026 · Swift, AppKit, SwiftUI, Core Graphics, AVFoundation, ServiceManagement

A macOS menu bar app that lets the brightness keys dim below the lowest setting and boost into HDR above the highest, on displays that support it. It opens the display's HDR range with a tiny paused HDR video, then scales the screen's color tables from a saved original. A separate guardian process restores those tables if the app crashes or is killed, and every recorded restore matched the original exactly. It has 110 tests and ships as a free community beta on GitHub.
