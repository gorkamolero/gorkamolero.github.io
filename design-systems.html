Chessable Edge

Frontend engineer, Chessable · 2020–2022 · React, Clutch, npm, Storybook

Chessable Edge was Chessable's design system and UI component library. We built it in React with Clutch, a visual builder for React, and published it to npm as @chessable/edge, with its core split into a package of its own. Three teams were using it in production.

The video is the guide for developers I made for the teams adopting it. It covers what Edge is, how Clutch works, how to get started, and where the system was going next: a shared process, a public roadmap and documentation generated with Storybook.

openroadie

Roadie · 2026 · React, Tailwind, Storybook

openroadie's interface runs on @roadiehq/ui, the design system I built for it. It has about sixty components documented in Storybook, from forms, tables and drawers to the AI elements for agent conversations: messages, reasoning, tool calls and chain of thought. Its tokens cover color for light and dark themes, type, sizing, motion and z-index, and the code editor has a token set of its own.
